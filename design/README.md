# Design inputs for v0.3

- `kb-v2.json`: the 99-entry library (40 wrong, 47 how, 12 what) with the lay-word synonym map and the keys list. It is the same library the SolidWorks Day post uses, so the add-in and the post must answer a question the same way.
- `pane-v0.2-2026-09-28.png`: the v0.2 pane in SolidWorks 2026, as Mr. Pina saw it on 2026-09-28. His verdict: no student would open this and start using it.
- `reference/IDEA100_D04_SolidWorks-Day.html`: the SolidWorks Day post. Its search engine (tokenize, stopwords, stem, Damerau-Levenshtein, synonyms, scoring) and its SolidWorks-style look are the reference for the pane.
